# TabBar 图标说明

请将以下图标文件放置在此目录：

## 需要的图标文件

1. **home.png** - 首页图标（未选中状态）81x81px
2. **home-active.png** - 首页图标（选中状态）81x81px
3. **store.png** - 门店图标（未选中状态）81x81px
4. **store-active.png** - 门店图标（选中状态）81x81px
5. **visit.png** - 拜访图标（未选中状态）81x81px
6. **visit-active.png** - 拜访图标（选中状态）81x81px
7. **order.png** - 订单图标（未选中状态）81x81px
8. **order-active.png** - 订单图标（选中状态）81x81px

## 图标规格

- 尺寸：81x81 像素
- 格式：PNG
- 背景：透明
- 颜色：
  - 未选中：#999999（灰色）
  - 选中：#1890ff（蓝色）

## 临时方案

如果暂时没有图标，可以：

1. 使用在线图标生成工具（如 iconfont.cn）
2. 或者先注释掉 app.json 中的 tabBar 配置
3. 通过页面导航代替 TabBar

## 推荐图标资源

- IconFont: https://www.iconfont.cn/
- Flat Icon: https://www.flaticon.com/
- Icons8: https://icons8.com/
